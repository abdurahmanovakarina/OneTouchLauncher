# OneTouch Home — лаунчер для планшета

Нативный лаунчер для Android 16 по макету «OneTouch Home OS — экран колонки».
Стек: Kotlin, Jetpack Compose, minSdk 29 (Android 10), targetSdk 36 (Android 16).
Сторонних библиотек нет, только AndroidX. APK весит около 3 МБ, и на Dimensity 6300 с 8 ГБ ОЗУ лаунчер работает плавно.

## Сборка

1. Установите Android Studio (Narwhal 2025.1 или новее) и откройте эту папку: **File → Open**.
2. Дождитесь синхронизации Gradle. Нужный SDK 36 Android Studio скачает сама.
3. По желанию для точного шрифта из макета скачайте **Inter Tight** с fonts.google.com
   и положите четыре файла из папки `static/` в `app/src/main/assets/fonts/`.
   Список файлов — в `README.txt` в той же папке. Без них лаунчер работает на системном шрифте.
4. **Build → Build APK(s)**, или из терминала: `./gradlew assembleRelease`.
   Готовый файл: `app/build/outputs/apk/release/app-release.apk`.
   Release для удобства подписан debug-ключом. Для публикации подключите свой ключ.

## Установка на планшет

1. Включите на планшете «Для разработчиков» → «Отладка по USB», подключите кабель и нажмите **Run** в Android Studio.
   Можно и без кабеля: скопируйте APK на планшет и откройте его.
2. Нажмите кнопку «Домой» и выберите **OneTouch Home → Всегда**.
   То же можно сделать в настройках лаунчера: «Лаунчер по умолчанию».
3. При первом запуске лаунчер спросит доступ к календарю и микрофону.
4. Для управления музыкой включите доступ к уведомлениям:
   «Настройки лаунчера → Управление музыкой». Он нужен только для того, чтобы видеть и переключать треки.

**Настройки лаунчера** открываются долгим нажатием на логотип или кнопкой-шестерёнкой на странице «Приложения».

## Что сделано по макету

| Экран макета | Что работает |
|---|---|
| Главный экран · тёмная / светлая | Часы, дата, погода по часам (Open-Meteo, без ключа), события из календаря планшета, ближайший будильник, круглый плеер для любой играющей музыки, плитки, быстрые сценарии, камера (пока заглушка) |
| Главный 2 · Минимал | Крупные часы, большой плеер, плитки |
| Страница 3 | Вместо «Музыки» — **все приложения планшета** с поиском. Без этого лаунчером нельзя пользоваться. Долгое нажатие открывает сведения о приложении |
| Сон 1–4 (Орбиты, Свет, Музыка, Ночь) | Заставка после бездействия (1/2/5/10 мин). В режиме «Авто» ночью — «Ночь» с приглушённой подсветкой, при музыке — «Музыка», иначе — «Орбиты». Есть сдвиг против выгорания экрана |
| Голосовой ассистент | Касание «Скажите «OneTouch»» → распознавание речи на русском. Команды: «включи свет на 50», «выключи свет», «закрой шторы», «включи охрану», «спокойной ночи», «ухожу из дома», «кино», «пауза», «дальше», «громче», «открой YouTube», «погода», «который час», «заставка» |
| Комната · Гостиная | Кольцо яркости (тянуть пальцем, двойное касание — вкл/выкл), сцены, температура света, переключатели устройств |
| Сценарии | 6 сценариев, запуск касанием |
| Музыка · плеер | Обложка, перемотка, кнопки, громкость планшета, переход в приложение-источник |

Тема переключается сама: светлая с 07:00 до 20:00, тёмная вечером. Можно закрепить вручную.
После 20:00 в колонке справа показан план на завтра, как в макете.

## Демо-режим умного дома

Плитки, комната и сценарии меняют состояние на экране и запоминают его, но реальными устройствами не управляют.
Чтобы подключить настоящие устройства (Home Assistant, Tuya, Zigbee-шлюз), реализуйте интерфейс `HomeBackend`
в `data/SmartHome.kt` и передайте его в `SmartHome(...)`. Интерфейс лаунчера менять не нужно.

## Пока не сделано (есть в макете)

Первичная настройка (язык, Wi-Fi, вход по QR, голос), заказ OneTouch GO и «мастер в пути», будильник «Рассвет»,
поиск и добавление устройств, редактор сценариев, ТВ-пульт и экран телевизора, тексты песен.
Для этих экранов нужен ваш сервер или устройства. Их можно добавить следующим этапом.

Голосовая активация без касания («горячее слово» OneTouch) требует отдельного движка, например Picovoice Porcupine.
Сейчас ассистент запускается касанием.

## Структура

```
app/src/main/java/uz/onetouch/home/
  MainActivity.kt          — лаунчер (HOME), полноэкранный режим, навигация, заставка по бездействию
  LauncherViewModel.kt     — состояние, таймеры, голосовые команды
  data/                    — погода, календарь, музыка, приложения, умный дом, голос, настройки
  ui/theme/Theme.kt        — палитры из макета, масштабирование 1280×800 под любой экран
  ui/components/           — иконки (SVG-пути из макета), орбиты, плитки, кнопки, слайдеры
  ui/screens/              — экраны
```

Макет нарисован для 1280×800. Все экраны масштабируются под фактическое разрешение планшета
(1920×1200, 2000×1200 и т. д.) с сохранением пропорций.
